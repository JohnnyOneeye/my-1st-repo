# version-control-practice
Commits create a record of changes, allow developers to track progress, collaborate safely, recover mistakes, and manage different versions of a project.
Commit little and often to make changes easier to track and fix.make it easy for teams to work togetherUse clear commit messages so everyone understands what was changed and why.
Evidence Checklist
Why Commits Are Important

Commits create a structured history of changes, allowing developers to track progress, manage updates, and recover previous versions when needed.

Skills Demonstrated

Refactored code using commits to document improvements.

Fixed mistakes by creating new commits and maintaining a clear project history.

Demonstrated how to undo changes while preserving work:

git reset --soft HEAD~1

Demonstrated how to safely reverse changes using:

git revert <commit-hash>
Git Commands Used
git add .
git commit -m "Refactor code"
git log --oneline
git reset --soft HEAD~1
git revert <commit-hash>
Learning Outcome

This task demonstrated how Git commits support version control by providing a reliable history of changes, enabling code recovery, and improving project maintainability.
