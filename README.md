# version-control-practice
Version control is a system that helps developers track changes made to files, especially source code. It records different versions of a project over time so developers can review history, restore older versions, and work safely without losing work.

A version control system acts like a detailed “save history” for a project.
Developers use version control for several important reasons:
It keeps a history of edits, showing:
what changed
who changed it
when it changed
why it changed
Collaboration
Multiple developers can work on the same project at the same time without overwriting each other’s work.

Developers can create separate branches to test new features without affecting the main project.
Version control helps teams organise software releases and maintain stable versions of applications.
Improve Accountability.
